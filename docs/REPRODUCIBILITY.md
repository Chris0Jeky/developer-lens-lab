# Reproducibility

`uv.lock` pins the Python environment. The DatasetCard records generator ID/version,
classification, observation/system counts, and coverage counts. The EvaluationBundle records model
versions and parameter hashes, split seed families/windows, run seeds, and bounded resources. The
top-level run manifest records the lab commit, uv lock hash, input snapshot and dataset-recipe
checksums, and every artifact reference. Explicit generator parameters and a normalized command ID
remain a documented follow-up rather than a current manifest claim.

Manifests must not contain absolute/local paths, usernames, environment names/values, credentials,
provider IDs, machine names, exact host timings, or stable real-scope hashes. Hashes address
lab-local generated objects and prove bytes; they do not imply anonymity or authorize cross-repo
linkage.

Normal smoke flow:

```powershell
uv sync --locked --all-groups
uv run dllab context verify
uv run dllab benchmark wb-c1 --smoke
uv run dllab run reproduce wbc1_smoke
uv run dllab report build wbc1_smoke
uv run pytest
```

A run ID is append-only and single-use. Supply `--run-id <new_opaque_id>` to the benchmark command,
then pass that ID to `run reproduce` and `report build`, when the default scope already exists.

The benchmark refuses a dirty tracked/unignored worktree because its recorded lab commit must name
the executing code. It exclusively reserves the run scope and writes the dataset recipe, plan hash,
frozen thresholds, and method-parameter hashes to an append-only custody record before the
final-holdout factory runs. Replay verifies the recorded lab commit, `uv.lock`, product contract
snapshot, dataset recipe, custody record and object, both ResearchPack Parquet relations, both result
Parquet files, PELT summary, reports, and EvaluationBundle by stored digest plus regenerated bytes.
Larger benchmarks require the explicit `--full` flag and never download data or weights at runtime.

Contract schemas are deterministic tracked outputs:

```powershell
uv run dllab contracts check
```

The ResearchPack consumer mirror comes from lab validation models. A canonical producer snapshot is
accepted only through `dllab contracts sync --from <checkout> --ref <full commit>`; sync reads the
two fixed paths from Git objects and records their byte checksums without persisting the checkout
path.
